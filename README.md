# README: VIT-O-PIA (v2.0) — Campus Management Dashboard

## What is VIT-O-PIA?
**VIT-O-PIA** is a futuristic, "cyberpunk-themed" web dashboard designed for students at VIT Bhopal.
It acts as a central hub where students can track their grades, view their class schedules, find their way around campus, and book resources like labs or library slots.

The interface uses a high-contrast "Neon" aesthetic (blues, purples, and pinks) to make the academic experience feel like a high-tech terminal.

---

## Main Features

### 1. Dashboard (Home)
* **System Status**: Shows live stats like how many systems are online and the current network latency (2ms).
* **AI Suggestions**: Provides smart tips, such as recommending the best room for a study block.
* **Proctor Feed**: A scrolling news section for urgent campus alerts, like attendance policy updates or maintenance news.

### 2. Campus Map (Topography)
***Interactive Grid**: A visual layout of the 200+ acre campus.
***Location Data**: Clicking on a building (like AB1, AB2, or the Hostel) shows a description of what is inside and its rules.
***Live Intel**: Displays the current weather (e.g., 32°C) and the status of the campus shuttle buses.

### 3. Chronos Link (Timetable)
* **Weekly Schedule**: A color-coded table showing classes from Monday to Friday.
* **Venue Tracking**: Lists the specific room numbers (like AB02-230) for every subject so students never get lost.

### 4. Neural Calendar
* **Academic Timeline**: A full view of the months (April/May 2026).
* **Event Labels**: Marks "Instructional" days, holidays (like Ambedkar Jayanti), and "Remote Learning" days.
* **FAT Countdown**: A live timer showing how many days are left until the Final Assessment Test (FAT) begins.

### 5. Exam Terminal
* **Grade Tracker**: View marks for Internal exams, Midsems, and Endsems across all subjects.
* **Performance Analysis**: Displays the current CGPA (e.g., 8.74) and uses AI to predict the final CGPA at graduation.
* **Grade Badges**: Automatically assigns letter grades (S, A, B, C) based on the total score out of 100.

### 6. Resource Booking (Terminal Book)
* **Lab & Library Access**: Students can select a specific lab (like AB1-301) and see how crowded it is.
* **Slot Locking**: Choose a specific time slot (from 09:00 to 17:00) and "execute" a reservation for study or project work.

---

## Technical Details
* **Language**: Built using standard HTML5, CSS3, and JavaScript.
* **Fonts**: Uses *Orbitron* for a sci-fi look and *JetBrains Mono* for technical data.
* **Visual Effects**: Includes "Scanline" animations and "Glitch" transitions to maintain the digital terminal vibe.
